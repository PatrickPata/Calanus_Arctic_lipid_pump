This is the repository for the scripts associated with the manuscript "Calanus copepods are as important as marine snow in Arctic vertical carbon flux" by Pata et al. (2026).

The CTD data is available through https://catalogue.amundsenscience.com/.
The copepod image data is available through EcoTaxa with the following project IDs: 5108, 10101, 14844, 14859, 17498, 18084.
The Hydrobios net taxonomy data may be requested from the authors through Cyril Aubry and the DFO KEBABB program.

Please contact patrick.pata.1@ulaval.ca for any questions and assistance regarding the scripts.
